# Eat and food collection implementation plan

**Goal:** Deliver the approved `/eat` game: random foods, rarity, humorous reactions, saved discoveries/counts, and a short cooldown. Beta first, following the current release workflow.

**Design:** 24 foods in four rarity pools (70% common, 22% rare, 7% epic, 1% legendary). One durable record per guild/member contains discoveries, counts, cooldown and recent interaction receipts. Serialize rolls with a local mutex and PostgreSQL advisory lock; save before reporting success. No coins or economy changes. Collection views are private and read-only.

**Command ruling:** Discord commands with subcommands cannot also run bare. Preserve `/eat` by using an optional `action` choice: `/eat action:collection`, `/eat action:guide`, plus a My collection button on results.
