# Faith and daily Bible implementation plan

**Goal:** Implement the approved Faith category design, daily English Bible verses, commands and dashboard controls. Start in Beta.

**Architecture:** A local, attributed World English Bible collection supplies deterministic daily verses. A guild service validates settings and manages a PostgreSQL delivery ledger, using the existing shared persistence, mutex, configuration and interaction helpers. An authenticated dashboard route and a Beta command share that service.

**Scope:** Preserve existing channels and messages. Add a read-only daily channel and pinned guidance through an idempotent Beta setup script. No automatic religious role assignment, pings, generated scripture, Main release messages or changes to EditIL Assistant. English/WEB is the initial supported translation. Default time: 09:00 Asia/Jerusalem.

## Review focus
Unknown or misspelled timezones must fail validation. A failed post must be retried without flooding. A successful send followed by failed persistence must be reconciled. Public viewers must never gain write access. Channel moves, deletion, missing permissions and restarts must not cause duplicate posts.
