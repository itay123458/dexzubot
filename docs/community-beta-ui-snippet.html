Community command guide
/invite-rewards balance · /invite-rewards claim · /invite-rewards panel
Check qualifying invites, claim new milestones or publish a panel. Publishing requires Manage Server.
/beta-staff applications · /beta-staff leave · /beta-staff activity
Open the application, leave or current activity controls privately in Discord.
/beta-staff activity-start hours · /beta-staff activity-end id
Reviewers can start a check for 1–336 hours or close it by its check ID.
Invite rewards
Publish the invite rewards panel, then use its balance and claim buttons. Only attributed, retained members qualify; each milestone can be claimed once.
Applications
Use the application panel to start, resume or cancel a private application. Answer one question at a time. Review submitted answers here.
Leave of absence
Use the leave panel to request 1–14 days away. Reviewers approve or deny requests here; approved leave expires automatically.
Activity checks
Start a check below, then staff respond using its Discord button. Close a check to see responded, missing and excluded members. No reminder DMs are sent.
Tickets and server information
Category buttons open General support, Report a member or Partnership tickets using the existing ticket setup. Server information panels include current statistics and selected channel links.
Optional DMs
DM switches apply only to the involved member’s application, ticket or leave updates. Delivery can fail when DMs are closed; the saved result remains visible here.
